Tutorial: Como fazer isso no React

Veja abaixo o guia passo a passo para criar este projeto do zero usando React, Vite e Ethers.js.

1. Preparando o Ambiente

Você precisa do Node.js instalado no computador. Após garantir isso, abra seu terminal e crie um novo projeto Vite:

npm create vite@latest minha-carteira -- --template react

Depois, entre na pasta e instale as dependências básicas:

cd minha-carteira
npm install

2. Instalando o Ethers.js

O Ethers.js é a biblioteca que facilita a comunicação com a blockchain. Instale via npm:

npm install ethers

3. Escrevendo o Código (App.jsx)

Abra o arquivo src/App.jsx e substitua pelo código abaixo. É aqui que a mágica acontece!

// src/App.jsx
import { useState, useEffect } from 'react';
import './App.css';
import { ethers } from 'ethers';

function App() {
  const [carteira, setCarteira] = useState(null);
  const [saldo, setSaldo] = useState(null);

  // Função para conectar
  const conectar = async () => {
    if (window.ethereum) {
      try {
        // 1. Pede permissão para conectar
        const provider = new ethers.BrowserProvider(window.ethereum);
        const signer = await provider.getSigner();
        const endereco = await signer.getAddress();
        
        setCarteira(endereco);
        
        // 2. Busca o saldo (opcional)
        const balance = await provider.getBalance(endereco);
        setSaldo(ethers.formatEther(balance));
        
      } catch (error) {
        console.error("Erro ao conectar:", error);
      }
    } else {
      alert("Por favor, instale a MetaMask!");
    }
  };

  // Função para desconectar (simulada no Front)
  const desconectar = () => {
    setCarteira(null);
    setSaldo(null);
  };

  return (
    <div className="app-container">
      <h1>Minha DApp</h1>
      
      {!carteira ? (
        <button onClick={conectar}>Conectar Carteira</button>
      ) : (
        <div>
          <p>Conectado: {carteira}</p>
          <p>Saldo: {saldo} ETH</p>
          <button onClick={desconectar}>Desconectar</button>
        </div>
      )}
    </div>
  );
}

export default App;

4. Executando o Projeto

Volte ao terminal e rode o comando de desenvolvimento:

npm run dev

Clique no link local (ex: http://localhost:5173) que aparecerá no terminal e teste sua aplicação!
