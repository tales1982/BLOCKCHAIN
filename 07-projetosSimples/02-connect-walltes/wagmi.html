Manual Completo: conectar MetaMask com wagmi@3.3.1

Este manual descreve o passo a passo completo e o codigo necessario para conectar a MetaMask em um projeto React + Vite com wagmi 3.3.1.

1) Requisitos e versoes (projeto real)

Use exatamente estas versoes para evitar incompatibilidades. 

wagmi: ^3.3.1
viem: ^2.44.1
@tanstack/react-query: ^5.90.16
react: ^19.2.0
react-dom: ^19.2.0
vite: ^7.2.4

Instalacao

npm install wagmi viem @tanstack/react-query

2) Configurando o wagmi (igual ao projeto)

Arquivo src/wagmi.ts real do projeto, usando as redes mainnet e sepolia com o conector injected (MetaMask). 

// src/wagmi.ts
import { http, createConfig } from "wagmi";
import { mainnet, sepolia } from "wagmi/chains";
import { injected } from "wagmi/connectors";

const URL_RPC_MAINET = import.meta.env.VITE_ALCHEMY_MAINNET_URL;
const URL_RPC_SEPOLIA = import.meta.env.VITE_ALCHEMY_SEPOLIA_URL;

export const config = createConfig({
  chains: [mainnet, sepolia], // redes usadas
  connectors: [injected()], // conector MetaMask
  transports: {
    [mainnet.id]: http(URL_RPC_MAINET),
    [sepolia.id]: http(URL_RPC_SEPOLIA),
  },
});

Os valores VITE_ALCHEMY_MAINNET_URL e VITE_ALCHEMY_SEPOLIA_URL devem estar definidos no arquivo .env na raiz do projeto. Nunca commite sua chave real em repositório publico.

3) Providers no entrypoint (src/main.tsx real)

No src/main.tsx, o app precisa estar dentro de WagmiProvider e QueryClientProvider. 

// src/main.tsx
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'
import App from './App.tsx'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { WagmiProvider } from 'wagmi'
import { config } from './wagmi.ts'

const queryClient = new QueryClient()

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <WagmiProvider config={config}>
      <QueryClientProvider client={queryClient}>
        <App />
      </QueryClientProvider>
    </WagmiProvider>
  </StrictMode>
)

4) Componente de conexao (src/ConectWallet.tsx real)

Este é o componente exatamente como está no seu projeto, usando useConnection, useConnect, useDisconnect e useConnectors do wagmi 3.3.1. 

// src/ConectWallet.tsx
import { useConnect, useDisconnect, useConnection, useConnectors } from 'wagmi'

const ConnectWallet = () => {
  const connection = useConnection()
  const connect = useConnect()
  const disconnect = useDisconnect()
  const connectors = useConnectors()

  const isConnected = connection.status === 'connected'
  const address = connection.address

  if (isConnected) {
    return (
      <div>
        <button onClick={() => disconnect.mutate()}>Desconectar</button>
        <br />
        conectado: {address}
      </div>
    )
  }

  return (
    <button onClick={() => connect.mutate({ connector: connectors[0] })}>
      Conectar MetaMask
    </button>
  )
}

export default ConnectWallet

5) Usar o componente na App (src/App.tsx real)

// src/App.tsx
import './App.css'
import ConnectWallet from './ConectWallet'

function App() {
  return (
    <>
      <ConnectWallet />
    </>
  )
}

export default App

6) Fluxo completo de conexao

  1. O navegador carrega o Vite e o React a partir do main.tsx.
  2. O WagmiProvider registra a config e as redes.
  3. O QueryClientProvider habilita o cache interno do wagmi.
  4. O botao chama connect() com injected() e abre a MetaMask.
  5. Ao aprovar, isConnected vira true e o endereco aparece.
