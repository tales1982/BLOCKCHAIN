Web3 Tutorial: React + Wagmi

Aprenda a conectar sua MetaMask de forma profissional e escalável.

1

Iniciando o Projeto com Vite

O Vite é o "bundler" mais rápido para React hoje. Vamos começar criando a estrutura base.

npm create vite@latest meu-app-web3 -- --template react-ts
# Siga os passos e depois:
cd meu-app-web3
npm install
2

Instalando as Bibliotecas Web3

Utilizaremos Wagmi para hooks, Viem para interagir com a rede e TanStack Query para gerenciar os estados.

npm install wagmi viem @tanstack/react-query
3

Configurando o Wagmi

Crie um arquivo chamado wagmi.ts para configurar os conectores e as redes.

import { http, createConfig } from 'wagmi'
import { mainnet, sepolia } from 'wagmi/chains'
import { injected } from 'wagmi/connectors'

export const config = createConfig({
  chains: [mainnet, sepolia],
  connectors: [ injected() ], // Aqui injetamos a MetaMask
  transports: {
    [mainnet.id]: http(),
    [sepolia.id]: http(),
  },
})
4

O Componente de Conexão

Este é o coração do seu app. Usaremos os hooks useAccount, useConnect e useDisconnect.

function WalletComponent() {
  const { address, isConnected } = useAccount()
  const { connect, connectors } = useConnect()
  const { disconnect } = useDisconnect()

  if (isConnected) return (
    <div>
      Conectado: {address}
      <button onClick={() => disconnect()}>Desconectar</button>
    </div>
  )

  return (
    <button onClick={() => connect({ connector: connectors[0] })}>
      Conectar MetaMask
    </button>
  )
}
